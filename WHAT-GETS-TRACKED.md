## 🎯 Key Takeaways

### What You Commit to Git

✅ **All handwritten source files** (YAML, MD, SH)
✅ **All knowledge bases** (embedded reference materials)
✅ **All infrastructure** (configs, scripts, docs)
✅ **Directory structures** (.gitkeep for sessions/)

### What Gets Regenerated

❌ **Compiled agents** (agents/*.md from YAML)
❌ **Runtime sessions** (conversation data)
❌ **Generated output** (BRDs, TSDs, guides, etc.)
❌ **Environment configs** (.env, local overrides)

## 🚀 Migration Impact

**When you clone this repo on a new machine:**

```bash
git clone <repo-url> frappe-experts
cd frappe-experts
```

**You get:**
- ✅ All 6 agent YAML source files
- ✅ All 8 sidecar instruction sets
- ✅ All 8 memory template structures
- ✅ All 37 knowledge base files (complete embedded docs!)
- ✅ All 11 workflow definitions
- ✅ All 7 workflow instruction sets
- ✅ Complete infrastructure (config, deploy, docs)

**You DON'T get (but don't need):**
- ❌ Compiled agent .md files → regenerated by `bmad install`
- ❌ Your old conversation sessions → user-specific
- ❌ Your old project outputs → project-specific
- ❌ Your environment configs → machine-specific

**Then run:**
```bash
bmad install frappe-experts
```

**Now you have:**
- ✅ Compiled agent .md files (fresh from YAML)
- ✅ Empty sessions/ folders (ready for new conversations)
- ✅ Empty data/ folders (ready for new projects)
- ✅ Fully functional module with ALL knowledge embedded

**Time to productivity:** ~5 minutes ⏱️

## ✅ Portability Checklist

When adding new content, ask yourself:

**Is this handwritten source?**
- ✅ YES → Track it (add to git)
- ❌ NO → Exclude it (.gitignore)

**Examples:**

| Content | Handwritten? | Track? |
|---------|--------------|--------|
| Agent YAML | ✅ YES | ✅ Track |
| Agent .md (compiled) | ❌ NO (from YAML) | ❌ Exclude |
| Sidecar instructions | ✅ YES | ✅ Track |
| Sidecar knowledge | ✅ YES | ✅ Track |
| Sidecar memories template | ✅ YES | ✅ Track |
| Session .md files | ❌ NO (runtime) | ❌ Exclude |
| Workflow YAML | ✅ YES | ✅ Track |
| Workflow instructions | ✅ YES | ✅ Track |
| Generated BRD | ❌ NO (output) | ❌ Exclude |
| config.yaml | ✅ YES | ✅ Track |
| .env | ❌ NO (secrets) | ❌ Exclude |
