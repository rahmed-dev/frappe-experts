# Quick Guide Knowledge Base

This folder contains documentation knowledge for the Quick Guide agent.

## Knowledge Files to Create

### UI Patterns:
- `erpnext-ui-patterns.md` - Standard ERPNext interface elements and terminology
- `ui-navigation-patterns.md` - How users navigate ERPNext (menus, tabs, buttons)

### User Workflows:
- `user-role-patterns.md` - Common tasks by user role (Sales, Stock, Accounts)
- `common-workflows.md` - Typical business process flows in ERPNext

### Documentation Standards:
- `plain-language-guide.md` - How to simplify technical terms for end users
- `action-oriented-writing.md` - Writing in active voice with direct instructions
- `formatting-guidelines.md` - When to use bold, bullets, numbers, tables

### Templates:
- `quick-reference-template.md` - Standard quick reference guide format
- `task-guide-template.md` - Step-by-step task documentation format
- `role-guide-template.md` - Role-specific workflow guide format
- `troubleshooting-template.md` - Common issues and solutions format

## Usage

Quick Guide loads this knowledge base on activation and references it when:
- Creating quick reference guides
- Translating technical features to user-friendly language
- Structuring documentation by user role
- Writing action-oriented instructions
- Formatting guides for maximum scannability
